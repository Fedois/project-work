# Titolo del Progetto 

Piattaforma digitale per la gestione dei servizi di un'impresa culturale.

## Tecnologie

- Frontend: React, TypeScript, Vite
- Backend: Node.js, Express, TypeScript
- Database: Prisma ORM e SQLite
- Deploy: Netlify e Render

## Avvio del progetto

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
npm run dev
```
